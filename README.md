# INST326-WorldofFoodProject
A digital recipe book, The World of Food, has two major features: a recipe search function and a recipe creation function. Users will be able to view recipes from all around the world using geographic filters and each recipe includes detailed instructions and ingredients lists.

Users can also can also contribute their own unique recipes by inputting data such as an ingredients list, instructions, total cooking time, and the users rating. These saved recipes can be saved for future use and shared with others in the food community.
